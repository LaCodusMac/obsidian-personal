# Portable Context Pack

The small hand-curated set of notes I hand a fresh AI so it knows my stack without
me re-explaining it. This — not a transcript archive — is what "not tied to any one
AI product" actually means in practice.

## Current state

The pack is a pointer list, not a copy. The notes below are the real ones; keep
them accurate and the pack stays accurate for free.

**Hand it these:**
- [[Hardware Inventory]] — what machines exist
- [[Network Stack]] — how they talk
- [[Synology NAS]] — where storage lives
- [[Hermes Agent]] — what's already automated
- This vault's `README.md` — how the vault is organized

**Plus a preferences paragraph** — how I want to be talked to, what I already know,
what I don't want re-explained. Keep it here so it's version-controlled:

> (write it here)

## Gotchas

- Resist the urge to grow this. If it's more than ~10 files it stops being portable
  and becomes a second vault you have to maintain in parallel.
- Do **not** feed raw `Inbox/` transcripts as context. They're unreviewed, often
  wrong, and mostly restate what's already in the entity notes.
