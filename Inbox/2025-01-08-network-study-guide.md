### **3. Key Topics to Study**

- OSI and TCP/IP models
- IPv4 and IPv6 addressing
- Subnetting and CIDR notation
- Common ports and protocols (e.g., HTTP, HTTPS, FTP, SSH, DNS)

#### **Network Infrastructure**
- Network devices (switches, routers, firewalls, access points)
- Cable types and connectors (e.g., Ethernet, fiber, coaxial)
- Wireless standards (e.g., 802.11a/b/g/n/ac/ax)
- WAN and LAN topologies

#### **Network Operations**
- Monitoring and performance tools
- Configuration management
- High availability and fault tolerance concepts

#### **Network Security**
- Firewalls, VPNs, and proxies
- Authentication protocols (e.g., RADIUS, TACACS+)
- Security policies and risk management

#### **Troubleshooting**
- Troubleshooting methodology
- Network monitoring tools (e.g., Wireshark, Netstat)
- Diagnosing common network issues (e.g., connectivity, bandwidth)
