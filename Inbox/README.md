# Inbox

**This is a staging area, not a knowledge base.**

Raw AI transcript exports land here. They are unreviewed, high-volume, low value
per file, and frequently contradict each other. Nothing in this folder should be
treated as true, cited, or handed to an AI as context.

## Setup

Add `Inbox` to Settings → Files & Links → **Excluded files**. Without this, every
search and quick-switcher lookup you do gets polluted by transcripts.

## The drain rule

1. Open a transcript.
2. Find the one or two facts worth keeping.
3. Write them into the relevant article in `Notes/`, in your own words, as
   *current state* — not as "ChatGPT said."
4. **Delete the transcript.**

Deletion is the mechanism. A `status: reviewed` flag you have to remember to flip
is a queue that never drains — which is exactly what happened to the ~50 files
sitting at `pending-review` since June.

## If the queue never shrinks

It won't. Almost nobody drains an import backlog. The honest move after a month of
no progress is to bulk-delete the folder and keep only what you've already mined —
the information you actually needed has, by then, already been re-derived by
working on the systems themselves.
