The rough flow is:

1. Connect fan to Dreo app over Wi-Fi
2. Install HACS in Home Assistant
3. Add the Dreo integration

```yaml
service: fan.set_percentage
target:
  entity_id: fan.living_room_fan
data:
  percentage: 70
```

Or:
```yaml
service: fan.oscillate
data:
  oscillating: true
```
