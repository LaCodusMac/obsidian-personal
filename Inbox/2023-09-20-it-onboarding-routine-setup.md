**1. IT Ticket Submission:**

**2. Active Directory Profile Creation:**
   - IT creates a profile in Active Directory with the following information:
     - A. User Email Address (First Initial, Last Name@minutemanst.com)
     - B. Temporary Password and Account login permissions
     - C. Account credentials, including name, local office information, phone number, etc.

**3. Office 365 Integration:**
   - Once the AD profile syncs with Office 365, IT issues proper software licenses to the new employee.

**4. Technology Procurement:**
   - IT purchases the requested technology, typically a laptop and phone.

**5. Hardware Setup:**
   - The hardware is shipped to arrive approximately a week before the new employee's start date.
   - Upon receiving the laptop, IT sets it up by installing Windows, ConnectWise Control, creating a new user profile, and updating the device.

**6. Apple Business Manager Account (Apple Only):**
   - For Apple devices, an account is created in the Apple Business Manager for the new employee.

**7. Onboarding Meeting:**
   - IT schedules a 1-hour meeting for the new employee's first day, which includes the following tasks:
     - A. Connecting the laptop to the MST Network to enroll the Intune profile.
     - B. Assisting the employee in creating a user password for their Office 365 account.
     - C. Setting up the Android or iPhone for Personal or Corporate use, connecting to MSTService or MSTGuest for Wi-Fi access.
     - D. Enrolling the user in Multi-Factor Authentication (MFA) using the Authenticator app or text via personal or work phone.
     - E. Logging the user into all necessary work applications on both devices (Office 365 and ConnectWise).
     - F. Ensuring devices are properly enrolled in the Mobile Device Management (MDM) platform with MST Wi-Fi access.
     - G. Setting up BitLocker encryption and OneDrive backup on laptops.
     - H. Providing a brief demonstration and ensuring the user is comfortable moving forward with the onboarding process.

**8. Support Information:**
   - Ensure the new employee has information on how to submit an IT ticket or contact IT in case they encounter any issues during their onboarding process.
