Red wine doesn't become dangerous after opening, but it does oxidize. Eventually it starts tasting:
- Flat
- Vinegary
- Nutty/cardboard-like
- Raisiny or cooked

A quick test:
1. Pour a tiny splash.
2. Smell it.
   - If it smells like wine, berries, oak, vanilla, etc. → probably drinkable.
   - If it smells like vinegar, nail polish remover, or sour fruit → dump it.
3. Take a small sip.
   - If it tastes dull but okay, drink it.
   - If it tastes sour, sharp, or unpleasant, toss it.
